Como funciona

Consulte de forma simples e segura

Você informa seus dados, confirmamos sua identidade e então podemos apresentar as próximas opções disponíveis para o atendimento.

1

Informe seu CPF

O CPF é validado localmente pelos dígitos verificadores para evitar erros de digitação.

2

Validação automática

Não é feita consulta externa de dados pessoais: o sistema apenas verifica se a estrutura do CPF é válida.

3

Continue no WhatsApp

Com um CPF válido, você é direcionado ao WhatsApp para continuar o atendimento.

🔐

Proteção dos seus dados

A validação do CPF é feita diretamente no navegador pelos dígitos verificadores. Não há consulta a uma base externa nem uso de chave de API nesta etapa.

Dúvidas frequentes

Antes de continuar

O CPF é consultado em alguma base externa?

Não. Nesta etapa, o sistema apenas verifica localmente se os dígitos verificadores do CPF são válidos.

Essa validação confirma a identidade do titular?

Não. Ela confirma somente que o número informado possui uma estrutura de CPF válida. O atendimento continua pelo WhatsApp.

O que acontece se o CPF for inválido?

O sistema informa o erro e não libera o redirecionamento para o atendimento.
